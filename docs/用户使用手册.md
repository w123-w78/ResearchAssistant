# 智能科研助理 —— 用户使用手册

> 基于 RAG + Agent 的论文知识库问答系统
> 适用于：Windows / Linux / macOS，Python 3.10+

---

## 一、环境准备

### 1.1 安装依赖

```bash
# 创建虚拟环境（推荐）
conda create -n research_assistant python=3.10
conda activate research_assistant

# 安装依赖
pip install -r requirements.txt
```

核心依赖只有 5 个：`numpy`、`PyYAML`、`requests`、`pymupdf`、`streamlit`。
`jieba`、`python-docx` 缺失时系统会自动降级（不影响启动）。

### 1.2 配置 API Key（三选一）

系统使用阿里云 DashScope（通义千问）提供 LLM / Embedding / Rerank 能力。

**方式一：`.env` 文件（推荐）**

在项目根目录创建 `.env`（可直接复制 `.env.example`）：

```
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx
```

**方式二：环境变量**

```bash
set DASHSCOPE_API_KEY=sk-xxxxxx         # Windows
export DASHSCOPE_API_KEY=sk-xxxxxx      # Linux / macOS
```

**方式三：配置文件**

编辑 `config.yaml` 的 `llm.api_key`。

> Key 获取：阿里云百炼控制台 → API-KEY 管理。
> **注意**：不要将真实 Key 提交到 Git（`.env` 已在 `.gitignore` 中）。

## 二、启动系统

### 2.1 Web 界面（推荐）

```bash
streamlit run src/frontend/app.py
```

浏览器打开 http://localhost:8501 。

### 2.2 命令行演示

```bash
python scripts/cli_demo.py              # 自动生成示例论文并跑通全链路
python scripts/cli_demo.py -i           # 交互式提问
python scripts/cli_demo.py --model qwen-max
```

### 2.3 离线自检（不需要 API Key）

```bash
python scripts/smoke_test.py            # 34 项冒烟测试
pytest tests/                           # 27 项单元测试
```

### 2.4 Docker 部署（可选）

```bash
cd docker && docker-compose up -d
```

## 三、界面功能说明

启动后为三栏布局：

### 3.1 左侧：知识库管理

| 功能 | 操作 |
|---|---|
| 上传论文 | 拖拽或选择文件，支持 PDF / Word / TXT / Markdown，可多选批量 |
| 开始导入 | 点击"开始导入"，显示进度条与逐文件状态（✓成功 / ✗失败 / ⊘跳过） |
| 文档列表 | 显示标题、块数、类型、索引状态；点击 🗑 删除 |
| 会话管理 | "＋新建会话"；点击历史会话切换（历史记录从 SQLite 恢复） |
| 系统状态 | 展开查看 LLM / 向量库 / Embedding / 数据库 / 工具集健康状态 |

### 3.2 中部：对话窗口

- 输入问题后回车发送
- 回答以**打字机效果**流式输出，支持 Markdown 渲染
- 句末的 `[1]` `[2]` 为引用标记，对应右侧"引用来源"
- 支持多轮追问（系统自动携带上下文）

### 3.3 右侧：Agent 推理过程

实时展示本次问答的决策链路：

- **指标卡片**：耗时 / 迭代轮次 / 工具调用次数 / Token 消耗
- **轨迹**：每一轮的 `Thought`（思考）→ `Action`（工具与参数）→ `Observation`（返回）
- **引用来源**：编号、论文标题、页码、相关度、原文片段

## 四、使用技巧

### 4.1 提问建议

| 问题类型 | 示例 | 系统行为 |
|---|---|---|
| 事实查询 | "DiffSeg 在 BraTS2021 上的 Dice 是多少？" | 检索 + 引用回答 |
| 对比分析 | "ViT 和 Swin Transformer 的区别？" | 双路检索 + 对比生成 |
| 归纳总结 | "这些论文用到了哪些数据集？" | 跨文档检索归纳 |
| 数值计算 | "(88.3-85.1)/85.1*100" | 直接路由到计算器 |
| 知识库查询 | "知识库里一共有几篇论文？" | 直接查询库统计 |

### 4.2 提升回答质量

1. **上传高质量 PDF**：文字版 PDF 效果远好于扫描件（扫描件需先 OCR）
2. **论文场景用 academic 分块**：`config.yaml` 中 `chunking.strategy: academic`
   可保护公式与表格不被切断
3. **问题尽量具体**：包含方法名、数据集名、指标名等专业术语
4. **善用追问**：系统保留上下文，"那它的消融实验呢？"这类追问可直接理解

## 五、常见问题（FAQ）

**Q1：启动时报"未配置 DashScope API Key"？**
A：按"1.2 配置 API Key"任一方式配置。若用环境变量，需**重启终端**后生效；
推荐改用 `.env` 文件，不受终端会话影响。

**Q2：上传 PDF 后检索不到内容？**
A：依次检查：① 是否为扫描件（图片型 PDF 需先 OCR）；
② 左侧文档列表是否显示状态为 `indexed`；
③ 展开"系统状态"确认向量库条数 > 0。

**Q3：日志提示"在线 Rerank 失败，降级为启发式"？**
A：Rerank 接口异常时自动降级，不影响使用。若持续失败，
可将 `config.yaml` 的 `retrieval.reranker.provider` 改为 `heuristic`
（纯本地，零网络开销）。

**Q4：回答没有引用标注？**
A：系统有兜底——模型未按要求标注时会自动列出 Top-3 来源。
可在右侧"引用来源"面板查看。

**Q5：数据存在哪里？如何备份？**
A：文档元数据、分块、对话历史、缓存、日志都在 `data/assistant.db`；
向量索引在 `data/index/`。备份这两个即可完整迁移。

**Q6：想清空知识库重来？**
A：删除 `data/assistant.db` 与 `data/index/` 下文件即可，重启系统会重建。

**Q7：换模型要改代码吗？**
A：不用，只改 `config.yaml` 的 `llm.model`（如 `qwen-max`）。

**Q8：没有网络能用吗？**
A：完整问答需要 DashScope 在线服务。离线可运行
`python scripts/smoke_test.py` 验证存储、分块、检索、路由等本地逻辑。

## 六、目录与数据说明

```
ResearchAssistant/
├── config.yaml              全局配置（改参数只动这里）
├── .env                     API Key（不要提交）
├── data/
│   ├── assistant.db         SQLite 主库（文档/分块/会话/缓存/日志）
│   ├── index/               向量索引（pickle，可重建）
│   ├── sample_papers/       通用示例语料（10 篇）
│   ├── papers_transformer/  同方向评测语料（10 篇 Transformer 论文）
│   └── uploads/             上传文件存放处
├── logs/app.log             运行日志
├── reports/                 评测集、评测数据、评测报告
└── docs/                    技术设计文档、本手册
```

**重建索引**：删除 `data/index/` 后重新导入文档即可，
文档元数据仍在 SQLite 中，无需重复上传原文件（重新 `ingest_directory` 亦可）。
