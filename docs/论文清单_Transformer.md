| 期刊 | 域名 | PDF 直链格式 |
|---|---|---|
| 计算机工程与应用 | **http**://cea.ceaj.org（**必须 http，https 不通**） | `/CN/PDF/<DOI>` |
| 计算机工程 | https://www.ecice06.com | `/CN/PDF/<DOI>` |
| 计算机科学 | https://www.jsjkx.com | `/CN/PDF/<DOI>` |
| 信号处理 | https://signal.ejournal.org.cn | `/cn/article/pdf/preview/<DOI>.pdf` |
| 计算机辅助设计与图形学学报 | https://www.jcad.cn | `/cn/article/pdf/preview/<DOI>.pdf` |
| 激光与光电子学进展 | https://www.researching.cn | `/ArticlePdf/m00002/<年>/<卷>/<期>/<文章编号>.pdf` |
| 中国图象图形学报 | cjig.ijournals.cn | ❌ 滑块验证，抓不了 |

要点：
- 前三个（cea / ecice06 / jsjkx）是 magtitech 同一套系统，DOI 直接拼即可
- jcad / signal 是另一套，`/cn/article/pdf/preview/<DOI>.pdf`
- cea.ceaj.org 的 `downloadArticleFile.do` 接口被 nginx 403，但 `/CN/PDF/<DOI>` 可用
- 下载时带 `Referer` 和浏览器 UA 成功率更高
- **DOI 不能猜**：猜错会静默返回另一篇同类文章（本次踩过），必须先从文章页
  `<meta name="citation_doi">` 提取真实 DOI再拼链接
